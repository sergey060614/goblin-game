# Игра с гоблинами

[![Deploy Status](https://github.com/sergey060614/goblin-game/actions/workflows/deploy.yml/badge.svg)](https://github.com/sergey060614/goblin-game/actions)

Классическая игра на реакцию: кликайте по гоблину молотком, пока он не исчез. У вас есть 5 пропусков.

## Технологии
*   JavaScript (ES6+ Classes)
*   Webpack (сборка JS, CSS и изображений)
*   Yarn (менеджер пакетов)
*   Deployed via GitHub Actions to GitHub Pages
